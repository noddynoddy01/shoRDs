## What a project is
A project is a workspace that groups analyses. Every user automatically gets a personal project ("My research") the first time they run an analysis. You can create more projects from the Projects screen.

## Project roles
Each member of a project has one role: Viewer (can read), Commenter, Editor (can start analyses) or Owner (can change member roles). A project must always keep at least one Owner. These project roles are unrelated to your profile type (student, mentor, ...) and to being a verified mentor or an administrator.

## Who can do what
Only members can open a project. Only an Owner can change who has which role. Starting an analysis in a project needs the Editor role or higher.
